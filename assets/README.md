# 🌹 Instrucciones para personalizar tu página de disculpas y recuerdos

¡Tu página web ya está 100% lista, animada y optimizada para subir a **Vercel**!

---

### 🎵 1. ¿Cómo poner la canción de La Princesa y el Sapo?
1. Consigue tu archivo de audio (por ejemplo *Ma Belle Evangeline* u otra canción que le guste).
2. Guarda el archivo con el nombre exacto:
   👉 `assets/cancion.mp3`
*(Nota: Mientras no coloques el archivo, la página incluye una dulce melodía de caja de música para que nunca se quede en silencio).*

---

### 📸 2. ¿Cómo agregar tus fotos juntos?
Coloca tus fotos dentro de esta carpeta `assets/` con estos nombres:
- `assets/recuerdo-1.jpg` : Primera foto (El día que se conocieron o primer recuerdo).
- `assets/recuerdo-2.jpg` : Segunda foto (Momentos de risas juntos).
- `assets/recuerdo-3.jpg` : Tercera foto o portada previa del video.

---

### 🎥 3. ¿Cómo agregar tu video?
Guarda tu video en:
👉 `assets/video.mp4`
Al presionar el botón de play en la página de recuerdos, el video se reproducirá automáticamente.

---

### 🚀 4. ¿Cómo subirla a Vercel (Totalmente Gratis)?
1. Entra a [https://vercel.com](https://vercel.com) e inicia sesión (o regístrate con GitHub / Google).
2. Tienes dos formas muy fáciles:
   - **Opción A (Arrastrar y Soltar con Vercel CLI o GitHub)**:
     - Sube esta carpeta a un repositorio de GitHub (o corre `npx vercel` en la terminal).
     - En Vercel haz clic en "Add New" -> "Project" -> selecciona tu repositorio y dale "Deploy".
   - **Opción B (Vercel CLI directo)**:
     - Abre una terminal en esta carpeta y ejecuta:
       `npx vercel`
     - Sigue las 3 preguntas en pantalla (presiona Enter a todo) ¡y listo! Te dará un enlace como `https://tu-proyecto.vercel.app`.

---

### 💖 5. Código QR en Forma de Corazón
En la página web verás un botón **"💾 Descargar QR con corazón"**.
Al hacer clic, se descargará automáticamente una imagen en alta definición con el código QR dentro del corazón para que puedas imprimirla en una carta física, pegarla en un peluche o enviársela por mensaje.
